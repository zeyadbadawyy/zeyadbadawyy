## ⭐ Featured Projects

### 🏆 CampusHub

A full-stack university social platform built from the ground up to provide students with a modern space for communication, content sharing, messaging, and social interaction.

CampusHub is designed as a real-world production-style application rather than a simple CRUD project, with a dedicated Go backend, PostgreSQL database, WebSocket-based real-time communication, cloud storage, authentication, notifications, and a highly interactive React frontend.

### Highlights

- 🔐 Authentication and user accounts
- 🏠 Social feed with posts, likes, comments, and saved posts
- 📸 Stories with image uploads, styling, viewing, and expiration
- 💬 Real-time private messaging
- ⚡ WebSocket-powered live updates
- 🔔 Real-time notifications
- 👤 User profiles and profile customization
- 🧑‍🤝‍🧑 User mentions with autocomplete and clickable profile navigation
- 🎞️ GIF support in posts, comments, and chat
- 🖼️ Image uploads and media previews
- 🌙 Dark mode
- 😀 Emoji support
- 🔎 Feed and user discovery features
- 🧠 Modern responsive interface with animated interactions
